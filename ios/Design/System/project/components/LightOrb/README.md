# LightOrb

A single light source: a hot white core, the light colour, and a halo and aura fading into the dark. It stands for the bracelet itself (its colour, whether it is glowing) and for colours you can pick. `pulse` breathes it on `duration-pulse`, in step with the bracelet; pair each peak with `haptic-pulse` when the person is waiting on it.

`light` takes a light name or the bracelet's own RGB colour.
