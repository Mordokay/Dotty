# Slider

A slider made of light. The fill is a gradient around the colour wheel, from `emptyLight` at empty to `light` at full, so the colour itself tells the level: as it fills, the thumb takes the colour of where it is, and it grows and glows brighter toward full. `emptyLight` defaults to a contrasting hue of `light`. The blend goes around the wheel, never through grey.

Pair it with the bracelet: send the value while dragging, and play a haptic every 2% that gets stronger toward full, so the level can be felt on both devices. While dragging, the thumb leaves a short comet trail of light (in the app).

Good pairs: vibration from lagoon (calm) to ember (strong); brightness from dusk (dim) to firefly (bright).
