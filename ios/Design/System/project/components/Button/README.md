# Button

Pill buttons, at least 52px tall (44px for `size="s"`). Pair every press with `haptic-tap`.

- **light**: filled with light and glowing in its colour. The one primary action on a screen ("Send touch", "Find my bracelet"). `light` sets the colour; it defaults to firefly, and follows the bracelet's colour where the action is about the bracelet.
- **glass**: everything else.
- **quiet**: text in a light colour, for low-emphasis actions next to others ("Not now").

Labels are verbs, sentence case, short.
