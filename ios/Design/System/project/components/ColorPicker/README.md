# ColorPicker

The bracelet's colours as small light sources. The chosen one swells and glows. Pair with `haptic-select`, and send the colour to the bracelet straight away so the person sees it there too. LEDs render colours differently from a screen, so the bracelet is the judge.

`colors` defaults to the seven light colours; pass `{name, value}` pairs (a light name or any colour) to change them.
