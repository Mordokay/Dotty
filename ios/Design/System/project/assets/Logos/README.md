# Logos

The Dotty firefly. `dotty-mark.svg` is the full-colour mark for night backgrounds; `dotty-mark-flat.svg` is for small sizes and print; the two one-colour marks are single ink (starlight `#F4EBD0` and heartwood `#3A2413`) for tab bars, stamps and watermarks; `dotty-app-icon.svg` is the 1024 px app icon source. The SVGs are generated by `Design/Logo/generate_logo.py` in the app repository.
